# ÍconeLab — Criador visual de ícones para aplicativos

Editor didático de ícones para estudantes, sem programação.

## Recursos
- 16 modelos iniciais de apps (mensagens, música, jogos, educação, finanças e outros).
- Biblioteca com dezenas de símbolos e formas geométricas.
- Textos com opções de fonte, cor, escala e rotação.
- Cores de fundo, upload de imagens, camadas e duplicação.
- Desfazer/refazer e prévia do ícone em miniatura.
- Exportação PNG em 800 × 800 pixels.
- Salvar e reabrir projetos editáveis em JSON.

## Abrir
Abra `index.html` em navegador moderno com conexão à internet. A biblioteca Fabric.js é carregada via CDN.

## Publicar no GitHub Pages
No repositório, abra **Settings → Pages**, escolha **Deploy from a branch**, selecione **main** e **/(root)**, depois **Save**. O GitHub informará quando o site estiver publicado.

## Proposta para sala de aula
1. Escolha um modelo de tema próximo ao aplicativo.
2. Personalize com letras, símbolos, formas e cores.
3. Confira a legibilidade em miniatura.
4. Salve o projeto editável em JSON para continuar.
5. Exporte o ícone em PNG.

## Limitações da versão inicial
Não há contas, sincronização em nuvem, colaboração em tempo real ou biblioteca com milhares de ilustrações. Os símbolos tipo emoji podem variar conforme sistema e fonte. O projeto não copia logotipos registrados de marcas famosas.
